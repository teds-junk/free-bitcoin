Vally & Agent Evals

Every checkpoint run on 2026-11-10 with Vally 0.21.0

You wrote a skill for an AI agent and it works when you try it. You cannot tell whether it works on another model, on the fifth run, or after your next edit. This course takes one small skill, a five-line guide to writing changelog entries, and improves it step by step, measuring every change. By the end you can edit a skill, or change the model under it, and say with evidence whether it got better and what a passing result costs, using checks a teammate can run too. The last five lessons put the same skill inside a small app and grade the app's agent, both inside Vally and after the fact.

Before you start

  • Node.js 22.15 or newer. Check with node --version.
  • Vally 0.21.0. Install it with npm install -g @microsoft/vally-cli, which adds a command-line tool to your machine. Check with vally --version.
  • A GitHub account with Copilot, signed in. Vally runs agents through GitHub Copilot. Follow Runtime Setup in the Vally docs. On our machine, being signed in to the Copilot command-line tool was enough.
  • A terminal and a text editor. The commands are written for macOS, Linux, or Windows with WSL.
  • Where you work. Download practice-starter.zip (32 KB) and unzip it. Lesson 1 has you copy practice-starter to a folder named practice. Everything you run and edit is in there.
  • For lessons 25 and 26: the app's libraries. In practice, run npm install --prefix app once. It installs the Copilot SDK and Vally's library into app/node_modules. Lesson 25 walks you through it.
  • Optional, for lesson 17: Ollama. One checkpoint runs a model on your own computer through Ollama 0.17.1 or later, with qwen3.5:9b (about 6.6 GB of disk; it used about 10 GB of memory on ours). It costs nothing in Copilot usage. Skip it and read our output instead if you prefer.
  • What it costs. Every agent run spends AI Credits from your Copilot plan, and Vally records them as AIU: one AIU is one GitHub AI Credit, which is $0.01 (checked 2026-11-10). A typical trial in this course cost about 2 AIU, about 2 cents; some models cost far less or more, and lesson 16 shows how to find out. Judge calls are extra, and Vally does not count them. Each lesson says what its checkpoint spends before you run it.
Models this course used

claude-haiku-4.5 and gpt-5.6-terra as the models under test, plus claude-haiku-5.5 in lesson 16, and claude-sonnet-5.5 as the judge. Checked on 2026-11-10. Model names differ between accounts and change over time. Lesson 1 shows how to list yours; use two of them wherever a command names ours.

How to use this course

  • Take the lessons in order. Each one ends with something you can do that you could not do before, and each changes the skill or what you know about it.
  • Every section is labelled with what it is for: how to think about something, how it works, or how to use it.
  • Lessons after the first open with questions from earlier lessons. Answer from memory before you look.
  • Your results will differ from ours. Models vary from run to run, which is the subject of the course. Where a page shows output, it says which parts are ours.
  • If a step does not work, compare your files with ours. The folder verified, beside practice-starter, has one folder per lesson. In each, practice holds our practice files as they stood at the end of that lesson, and output holds what each command printed in our run.
  • The reference sheets are the part to keep. When you come back to this later, start with the workflow guide. When a run goes wrong, the troubleshooting sheet lists what each symptom usually means.
