## Description
Every run so far had the skill installed, so we've never asked the plainest question: are the results better with it than with no skill at all? In this lesson we read an experiment file that names four variants of one eval, check it with a dry run, and run them all with one command. In our run both models passed five of five stimuli with the skill, against two of five and three of five without; the skill helped on the refactor and the security fix, made no difference on two others, and used slightly fewer tokens on both models. We also see that the first draft of the skill once made a result worse than no skill. Lesson 10 of Vally & Agent Evals.

Source: lessons/0010-is-the-agent-better-with-the-skill.html (Vally & Agent Evals). Vally docs: "Run Your First Experiment". SkillsBench, version 4, 2026 (a preprint; one benchmark of 87 tasks).
