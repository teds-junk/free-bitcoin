## Description
Eval files with setup, budgets, judges and several models can fail for reasons that have nothing to do with the skill. In this lesson we take four broken eval files, one fault each, and work through the same four questions on every one: is the eval valid, did it complete, why was the result unexpected, and does the fix work, proving each fix with the cheapest check. A command that YAML read as a mapping, a five-second time limit, a pattern that could never match, and a misnamed judge model: nearly every answer was already on disk. Two of the four looked like verdicts about the skill and weren't. Lesson 20 of Vally & Agent Evals.

Source: lessons/0020-when-a-run-goes-wrong.html (Vally & Agent Evals). Vally docs, "Debugging Evals".
