3. Agent evals from first run to a skill inside an app (full course)

## Description
You wrote a skill for a coding agent, and it works when you try it. But you can't tell whether it works on another model, on the fifth run, or after your next edit, or what each run costs. This course takes one short skill, which writes changelog entries, and measures it with Vally: reading what the agent really did, building graders we can trust, adding a judge for what code can't check, saying what a result does and doesn't support, pricing a passing trial, and turning the checks into a routine. The last part evaluates the same skill when an app, not a person, starts the agent. All 26 lessons in one video, with every command run for real.

Source: the Vally & Agent Evals course (lessons 1 to 26). Exercises and the workflow guide are on the course site.
