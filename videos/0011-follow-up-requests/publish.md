## Description
Every stimulus so far was one request. Real use goes on: someone asks for a follow-up. In this lesson we send three requests in order to the same session with `turns:`, give each turn its own grader with `turn:`, and read the diff Vally saves for each turn. In our run one model, which had not made up a number on any single request, cited a pull request number nobody gave in its third turn; in an earlier run of the same conversation it carried the second request's number into the third. One rule in the skill, and all six conversations passed: a small sample, and a failure no single-request test would have found. Lesson 11 of Vally & Agent Evals.

Source: lessons/0011-follow-up-requests.html (Vally & Agent Evals). Vally docs: "Writing Eval Specs", Multi-turn conversations.
