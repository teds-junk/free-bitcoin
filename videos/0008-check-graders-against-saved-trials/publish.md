## Description
The oracle can't test a grader that checks for absence, and it tries one correct answer. But we have real trials saved, good and bad. In this lesson we re-grade a saved run with `vally grade`, with no agent and no cost, then swap in a pattern that looks right and isn't. The oracle accepts it; the saved trials show it passing two entries with made-up numbers. We restore the pattern and end with the order to test any grader: oracle first, then a saved run of known failures, then agent runs. Lesson 8 of Vally & Agent Evals.

Source: lessons/0008-check-graders-against-saved-trials.html (Vally & Agent Evals). Vally docs: "CLI: grade".
