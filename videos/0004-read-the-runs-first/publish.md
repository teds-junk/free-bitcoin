## Title options

3. Discover errors, don't imagine them: reading agent runs with `--skip-grade`

## Description
So far we know one thing our skill gets wrong, on one tidy request. In this lesson we run six ordinary, messier requests on two models with `--skip-grade`, read all twelve saved patches, write one note per trial, and group the notes into failure modes. In our run that gave five: an invented pull request number, an entry for a change users can't see, a security fix filed under Fixed, a fix described by how it was coded, and a new heading that doesn't match the file. Each one turns out to be a question the skill left open. Lesson 4 of Vally & Agent Evals.

Source: lessons/0004-read-the-runs-first.html (Vally & Agent Evals). Husain and Shankar, "AI Evals FAQ" (reissued 2026-09-18). Shankar et al., "Who Validates the Validators?" (2024). Keep a Changelog 1.1.0.
