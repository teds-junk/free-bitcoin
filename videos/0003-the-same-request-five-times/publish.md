## Title options
1. The same request, five times: how often does an agent make the same mistake?
2. One run is one sample: counting agent behaviour with Vally (Vally & Agent Evals, lesson 3)
3. PASS, FLAKY, FAIL, ERROR: run an agent eval five times on each model

## Description
One model made up a pull request number and the other didn't, but each had run once. In this lesson we run the same request five times on each model with `--runs 5 --workers 2`, learn the four words Vally uses to sum up a stimulus's trials, and tally the ten saved patches. In our run one model made up a number in none of its five trials and the other in all five, and every trial passed. Lesson 3 of Vally & Agent Evals.

Source: lessons/0003-the-same-request-five-times.html (Vally & Agent Evals). Anthropic, "Demystifying evals for AI agents" (2026-01-09). Vally docs: "Scoring". The run-to-run variance figure is from a 2026 KTH preprint on SWE-bench Verified (one benchmark, not peer reviewed).
