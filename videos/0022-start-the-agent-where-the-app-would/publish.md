3. When an app, not a person, starts the agent

## Description
So far a person has typed every request. An app sends something different: one fixed sentence, and a workspace it has prepared. In this lesson we give the eval the app's own situation, running the release tool's setup command before the agent starts, and we grade with a hidden test that Vally adds only after the agent has stopped. In our run one model passed all five trials and the other two of five: it skipped the skill in two trials and wrote an entry for an internal refactor in three. The same skill that held for a person's wording did not hold for the app's. Lesson 22 of Vally & Agent Evals.

Source: lessons/0022-start-the-agent-where-the-app-would.html (Vally & Agent Evals). Anthropic, "Demystifying evals for AI agents" (2026). Vally docs, Writing Eval Specs, "Grader-only files".
