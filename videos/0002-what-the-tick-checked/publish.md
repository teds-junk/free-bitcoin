## Description
Two models wrote different changelog entries, one cited a pull request that doesn't exist, and both passed. In this lesson you read the eval file that told Vally what to do, then the results folder it left behind: the report, the grader's evidence, and what each trial used in tokens and cents. A pass means none of your graders objected, not that the result is correct. Lesson 2 of Vally & Agent Evals.

Source: lessons/0002-what-the-tick-checked.html (Vally & Agent Evals). Vally docs: "Eval Spec reference" and "Trajectory Format". GitHub Docs: "GitHub Copilot billing" (checked 2026-11-10).
