## Description
Everything we've graded so far is structure that code can see. Whether a changelog entry describes what users notice, and not how the fix was built, is a judgement about meaning. In this lesson we run three requests worded in coding terms, write our own yes or no for each of the twelve entries first, then add one yes-or-no LLM judge with a rubric and run it over the saved trials with `vally grade`. In our run the judge said no to four entries, three from one model, and agreed with us on eleven of twelve. Its reasons read well, and that is not yet evidence that it is right. Lesson 12 of Vally & Agent Evals.

Source: lessons/0012-a-judge-for-what-code-cannot-check.html (Vally & Agent Evals). Hamel Husain, "Using LLM-as-a-Judge". Vally docs: "Eval Spec reference".
