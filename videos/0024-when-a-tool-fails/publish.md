3. Write nothing, say why, stop retrying: grading how an agent copes

## Description
In practice the tracker or the network sometimes fails. Does the agent cope, and can we test that without breaking anything? In this lesson we decide what good looks like on a bad day, then use a simulation block to make one shell command fail the same way in every trial while everything else runs for real. Four graders check that the agent tried the tool, wrote no entry, stopped retrying, and said why. In our run both models passed all three trials each, and no trial invented a change; an earlier run shows a reply the judge failed. We also record a simulation block from a real run, and see why the answer has to be out of the workspace. Lesson 24 of Vally & Agent Evals.

Source: lessons/0024-when-a-tool-fails.html (Vally & Agent Evals). Vally docs, Eval Spec reference, "Simulation".
