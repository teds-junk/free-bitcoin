3. Cheap tokens, costly passes: a local model priced per passing trial

## Description
Every trial so far has run on models from a Copilot account. Teams often call a model through a provider they pay directly, or one they run themselves, and the same model name can behave differently there. In this lesson we point Vally's built-in executor at a provider block, add a fifth variant on a small open model served by Ollama on our own computer, and run it. In our run it passed two of five trials, and only one trial loaded the skill; no cost was recorded, so we price the tokens ourselves at a made-up rate: about 1.9 cents per passing trial, around nine times the cheapest hosted variant. Lesson 17 of Vally & Agent Evals.

Source: lessons/0017-a-model-from-your-own-provider.html (Vally & Agent Evals). Vally docs, Eval Spec reference: "Executor config & BYOK".
