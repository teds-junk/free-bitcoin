## Description
An agent can read and edit everything in its workspace, so a grading script left there can be satisfied without doing the work. In this lesson we keep one workspace to see exactly what an agent is given, then stage a grading script that reaches the graders and never the agent. In our run the script caught one model writing a new Unreleased heading without its brackets; one rule in the skill fixed it, and both models then passed all five stimuli. We also show, from an earlier run, a wrong answer that the same script passed, and why. Lesson 6 of Vally & Agent Evals.

Source: lessons/0006-keep-graders-out-of-reach.html (Vally & Agent Evals). Vally docs: "Eval Spec reference", Grading environment; "Writing Eval Specs", Grader-only files.
