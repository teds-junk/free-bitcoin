## Description
A skill that works when you try it can behave differently on another model. In this lesson you run one changelog request on two models with Vally, open the patch each run saved, and find that both passed while one of them made up a pull request number. Lesson 1 of Vally & Agent Evals.

Source: lessons/0001-it-works-for-me.html (Vally & Agent Evals). Vally docs: "Run Your First Eval".
