# Publish kit: What a passing trial costs

## Title options
1. What a passing trial costs: pricing agent eval variants by their passes
2. Tokens measure work, not price: cost per passing trial (Vally & Agent Evals, lesson 16)
3. Which model and reasoning effort is cheapest per pass? Four variants, sixty trials

## Description
A comparison table ends with a row of tokens, and it's tempting to read fewer tokens as cheaper. In this lesson we find where Vally records what each trial cost, add reasoning effort as a second thing to vary, and run four variants: two models at low and high effort, sixty trials in all. Every variant passed fifteen of fifteen, so the choice rests on cost: in our run a passing trial cost 0.21 AIU on claude-haiku-5.5 at low effort, against 2.76 and 2.83 AIU on gpt-5.6-terra, which used the fewest tokens. Lesson 16 of Vally & Agent Evals.

Source: lessons/0016-what-a-passing-trial-costs.html (Vally & Agent Evals). Kapoor et al., "AI Agents That Matter" (2024), a preprint.
