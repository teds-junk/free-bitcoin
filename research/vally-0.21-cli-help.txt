  --grader-plugin <specifier>       Grader plugin package to load (npm package
                                    or local path, repeatable) (default: [])
  --stimulus <name>                 Stimulus name to grade against (ATIF, or
                                    session run input, only)
  --workspace <path>                Path to agent workspace directory for
                                    file-based graders (overrides every input
                                    trajectory)
  --run-dir <path>                  Directory of a vally eval --output-dir run.
                                    Used to resolve trajectory.diffPath
                                    references in JSONL input so diff graders
                                    can re-grade from sidecar files.
  --artifact-dir <path>             Artifact/output directory written by the
                                    run, outside the graded workspace. Stamped
                                    onto trajectory.artifactDir so graders that
                                    read artifacts (e.g. custom-metrics) load
                                    their files (e.g. custom_metrics.json) from
                                    here. Marks it strict
                                    (trajectory.artifactDirStrict): for those
                                    graders a missing artifact fails here rather
                                    than silently falling back to a stale
                                    workspace copy; graders that don't read
                                    artifacts are unaffected. (Distinct from
                                    --run-dir, which resolves diffPath sidecars
                                    from an eval --output-dir run.)
  --diff-file <path>                Path to a unified diff file (e.g.
                                    changes.patch) to inject as the agent's
                                    workspace diff. Stamped onto trajectory.diff
                                    so diff-based graders and LLM judges using
                                    evidence:[diff] can grade offline without a
                                    git workspace.
  --assets-dir <path>               Setup/input assets directory staged outside
                                    the graded workspace (the managed
                                    EVALUATE_ASSETS dir). Stamped onto
                                    trajectory.assetsDir so graders that read
                                    setup inputs (program graders via
                                    EVALUATE_ASSETS, custom graders via
                                    GraderInput.trajectory.assetsDir) load their
                                    files from here rather than the graded
                                    workspace. Used by exporters (e.g. Harbor)
                                    that bake assets at a fixed non-workspace
                                    path.
  --param <key=value>               Set a param value (repeatable, e.g. --param
                                    MODEL=gpt-4o). Overrides eval param files
                                    and .vally.yaml. (default: [])
  -h, --help                        display help for command

  --judge-model <model>             Override the post-run comparison judge model

  --judge-reasoning-effort <level>  Override the post-run comparison judge

                                    not change trial grading)

  --grader-plugin <specifier>       Grader plugin package to load (npm package
