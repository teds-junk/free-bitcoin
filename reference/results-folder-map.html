Worth knowing

  • A trial that ended in ERROR has no verdict, and its stimulus shows dashes in the report's pass columns.
  • A failed judge call shows the stimulus as ERROR ("Grading error; verdict is invalid") while the trial's own status stays success. The saved trials can be judged again with vally grade.
  • A run whose commands: entry is not a string writes no eval-results.md: the same bad value breaks the report writer.
  • Saved results contain full paths from the machine that produced them. Share the eval files, not the results.
  • With --skip-grade, the ticks in the summary mean only that each trial finished.

Optional: two queries for results.jsonl

These need the jq tool and are typed in a run folder. Nothing in the course depends on them.

jq .gradeResult results.jsonl

Prints the grading part of each record: every grader's name, verdict and evidence. The last line is null, from the summary record.

jq '{model, trialIndex, reply: .trajectory.output}' \
  results.jsonl

Prints the model, trial number and final reply of each trial.
