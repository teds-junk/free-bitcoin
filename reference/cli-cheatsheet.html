Command cheat sheet

Verified 2026-11-10 · Vally 0.21.0

Every command the course used, cheapest first. Typed in the practice folder unless it says otherwise. Put your own model names and run folders in place of ours.

Commands that start no agent

Check an eval file for mistakes. Lesson 2

vally lint -e evals/changelog.eval.yaml

Run the graders on a correct answer, then on an untouched workspace. Lesson 7

vally oracle -e evals/changelog.eval.yaml --verbose
vally oracle -e evals/changelog.eval.yaml \
  --no-golden-input --verbose

Add --stimulus and a name to limit either to one stimulus.

Re-run the eval file's graders on a saved run. Typed in the run's folder. A judge grader spends one judge call per trial. Lesson 8

vally grade -e ../../../evals/changelog.eval.yaml \
  --run-dir . --verbose < results.jsonl

Inside one variant's folder of an experiment, the eval file is one level further up: -e ../../../../evals/changelog.eval.yaml. Lesson 18

The same, so that a failing verdict exits with 1. Meaningful only when every grader in the file can be re-graded. Lesson 21

vally grade -e ../../../evals/changelog.eval.yaml \
  --run-dir . --require-pass < results.jsonl

Grade a run Vally did not start: an ATIF file on standard input, the changed folder and its diff. Lesson 25

vally grade -e evals/release.eval.yaml \
  --stimulus since-last-release \
  --workspace app-run/repo \
  --diff-file app-run/change.diff \
  --verbose < app-run/trajectory.json

Judge two sets of saved trials side by side, and exit with 1 on a regression. Typed in an experiment's folder; each pair spends two judge calls. Lesson 19

vally compare \
  --baseline terra-before \
  --treatment terra-after \
  --judge-model claude-sonnet-5.5 \
  --fail-on-regression \
  --output terra-compare.jsonl

Print the last command's exit code. Run it straight after the command you want to check. Lesson 19

echo $?

Turn a saved run's shell calls into a simulation block to edit. Read its outputs before sharing them. Lesson 24

vally simulate record \
  results/lesson-22/2026-11-10T16-30-11-507Z

Print an experiment's plan. Lesson 10

vally experiment run \
  evals/with-and-without.experiment.yaml --dry-run

List your account's models, by asking for one that does not exist. Lesson 1

vally eval -e evals/one-request.eval.yaml \
  --model list-my-models \
  --output-dir results/models

List the reasoning efforts each model accepts, by asking for one that does not exist. Every trial stops before it starts. Lesson 16

vally eval -e evals/one-request.eval.yaml \
  --model \
  claude-haiku-4.5,claude-haiku-5.5,gpt-5.6-terra \
  --reasoning-effort list \
  --output-dir results/lesson-16-efforts

Commands that run agents

Run an eval file on two models, three trials each. Lesson 3

vally eval -e evals/changelog.eval.yaml \
  --model claude-haiku-4.5,gpt-5.6-terra \
  --runs 3 --workers 2 \
  --output-dir results/lesson-5-before

Run without grading, to read what comes back. Lesson 4

vally eval -e evals/six-requests.eval.yaml \
  --model claude-haiku-4.5,gpt-5.6-terra \
  --skip-grade --workers 2 \
  --output-dir results/lesson-4

Keep the workspace of each trial. One model only. Lesson 6

vally eval -e evals/one-request.eval.yaml \
  --model claude-haiku-4.5 \
  --workspace kept \
  --output-dir results/lesson-6-look

Show each failing trial's turns, tools, tokens and final reply. Lesson 20

vally eval -e evals/broken/entry.eval.yaml \
  --model claude-haiku-4.5,gpt-5.6-terra \
  --workers 2 --output-dir results/lesson-20 \
  --verbose

Run only the stimuli with a tag. Lesson 24

vally eval -e evals/release.eval.yaml \
  --tag case=tool-fails \
  --model claude-haiku-4.5,gpt-5.6-terra \
  --runs 3 --workers 2 \
  --output-dir results/lesson-24

Run a suite, and exit with an error if anything fails. Lesson 21

vally eval --suite quick \
  --model claude-haiku-4.5,gpt-5.6-terra \
  --workers 2 --require-pass \
  --output-dir results/lesson-21-quick

Run the trials through an executor loaded as a plugin in .vally.yaml. Lesson 26

vally eval -e evals/release.eval.yaml \
  --executor release-app \
  --model claude-haiku-4.5,gpt-5.6-terra \
  --workers 2 --output-dir results/lesson-26

Run every variant of an experiment. The models are named in the file. Lesson 10

vally experiment run \
  evals/with-and-without.experiment.yaml \
  --workers 2 --output-dir results/lesson-10

Run one variant only, here on a local model that serves one request at a time. Lesson 17

vally experiment run \
  evals/cost.experiment.yaml \
  --variant qwen-local \
  --workers 1 --output-dir results/lesson-17

Options

OptionEffect
-eThe eval file to use
--modelOne model, or several separated by commas
--runsTrials per stimulus, per model
--workersAgent sessions at once. Default 5; the course used 2, and 1 for a local model
--output-dirWhere to save. A folder named with the time is created inside
--skip-gradeRun the agents, grade nothing
--workspaceFor vally eval: keep each trial's workspace in this folder. For vally grade: the changed folder to grade
--suiteRun a suite from .vally.yaml in place of -e
--tagRun only stimuli with this tag, as key=value
--require-passExit with 1 if any stimulus fails. vally eval and vally grade
--reasoning-effortThe agent model's reasoning effort. An unknown value lists the accepted ones
--executorThe executor to run trials with, by name
--verboseOn vally grade and vally oracle: every grader's evidence. On vally eval: turns, tools, tokens and final reply of each failing trial
--stimulusFor vally oracle, and vally grade with an ATIF file: whose graders to use
--no-golden-inputFor vally oracle: apply nothing
--run-dirFor vally grade: where the saved diffs are
--diff-fileFor vally grade: the diff for diff graders, for a run Vally did not start
--dry-runFor vally experiment run: print the plan only
--variantFor vally experiment run: run one named variant
--baseline, --treatmentFor vally compare: the version compared against, and the version changed. A run folder or a results.jsonl each
--judge-modelFor vally compare: the judge. Not read from the eval file
--fail-on-regressionFor vally compare: exit with 1 when the treatment is significantly worse
--outputFor vally compare: a file for one JSON line per comparison

What the words and numbers mean

You seeMeaning
PASS, FLAKY, FAILEvery trial passed; some did; none did
ERRORA trial did not finish, or a grader could not reach a verdict. Not a verdict. Re-run, or leave it out and say so
Exit code 0 from vally eval or vally gradeThe run completed. Without --require-pass, stimuli may still have failed
Exit code 1 from vally eval or vally gradeAn ERROR, a refused eval file, or a failure with --require-pass
Exit code 1 from vally compareSome pairs could not be judged, or, with --fail-on-regression, the mean score and its whole range are below zero
"trial 1" in the terminalThe trial in folder 0

See Lesson 21 and Lesson 19.

Things that caught us

  • --workspace with several models stops with workspace-collision.
  • Five workers dropped three of ten sessions. Two workers still drops one now and then. With a local model, two workers made each trial wait for the other until both timed out.
  • An experiment takes no --model, --runs or --timeout; each variant sets its own, with the path in vary.
  • A re-grade fails every script grader (program or run-command), because the workspace is gone. So a re-grade with --require-pass of a file with a script grader exits 1 even when every trial passed.
  • vally compare --fail-on-regression gates on the judged score alone. Tokens rose for one model in our run, with a range wholly above zero, and it exited 0. Use budget graders for cost.
  • Without --judge-model, vally compare uses Vally's default judge, which may be a model you are testing.
  • vally experiment run --compare reports and does not gate; run vally compare afterwards for the step that can fail. (From the docs; not run by us.)
