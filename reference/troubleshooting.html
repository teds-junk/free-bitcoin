Troubleshooting

Verified 2026-11-10 · Vally 0.21.0

What a symptom usually means, where to look, and the cheapest proof that a fix worked. Rows are grouped by lesson 20's four questions, in the order to ask them: a verdict means nothing until the eval is valid and the trial completed. Rows marked "ours" come from runs in this course; rows marked "docs" come from Vally's Debugging Evals guide and have not been met in our runs. Each fix links to the lesson section that teaches it.

Before running anything again

Read what the failed run already saved: the console, the trial folder and results.jsonl. Re-run only when the fix changes something that happens before or during the agent's session, and then with one model if one is enough. Lesson 20

How far did a trial get?

The trial folder holdsWhat it means
metadata.json onlyNo agent session started. The failure came during setup.
events.jsonl, no workspace.patchThe agent started and was stopped before it finished.
events.jsonl and workspace.patchThe agent finished. Anything wrong is in the grading or the work.

A grader that did not reach a verdict has "status": "error" in its record and a score of 0. A grader that ran and said no has no status field, and also scores 0. Lesson 20
