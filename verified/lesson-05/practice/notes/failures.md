# Failure modes

- No rule for a missing pull request number: invents one or stops and asks (typo-fix, terra).
- Records a change users cannot see (refactor, both).
- Files a security fix under Fixed (security, both).
- Describes how the fix was coded (parser, haiku).
- New Unreleased heading does not match the file (after-release, haiku).
